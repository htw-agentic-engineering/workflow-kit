# workflow-kit

Vorlage für ein Agentic-Engineering-Setup in der Lehre.
Entsteht im Projektseminar Agentic Engineering an der HTW Dresden (WS 2026/27).


## Aufbau

| Ordner | Inhalt |
| --- | --- |
| `templates/` | Vorlagen für die Arbeit mit KI-Agenten (Issues, Spezifikation, Plan, AGENTS.md) |
| `notes/` | Interne Notizen und Recherchen des Projektteams – wird vor der Weitergabe entfernt |

## Für das Projektteam

- Namen von Ordnern und Dateien auf Englisch, Inhalte auf Deutsch
- Aufgaben laufen über Issues und das Projektboard
